# Task: 仿做真实网站 (C6)

**Status:** not started  
**Track:** css-engineering

## Goal

不自己凭空设计，直接找优秀网站「看图重做」。这会强迫你思考布局背后的为什么。

## 候选

Stripe / Linear / Vercel / Shopify / GitHub / Notion — 选 1 个 Landing + 1 个 App 页面。

## Rules

- 只看视觉效果，**不复制源码**（devtools 关掉，或只看截图）
- 截图存本地或 `notes/`，作为对照

## 每次重建要回答

- [ ] 这里为什么用 Grid / Flex？
- [ ] 这个区域 max-width 为什么是 1200（或其它值）？
- [ ] 这个 padding 为什么是 24？
- [ ] 这个字体为什么看起来舒服？（size / line-height / weight 组合）
- [ ] 这个按钮为什么放这里？（视觉层次 / 主行动）

## Hands-on

- [ ] Landing 页：hero + features + pricing 三段
- [ ] App 页：sidebar + header + 内容区（对照 C3 的骨架）
- [ ] 每次做完，把「观察 → 决策」各写一行

## Output

- [ ] `notes/c6-mimic-<site>.md` — 每个页面至少 5 条「为什么」的答案
- [ ] 2–3 个还原页面可运行

## Skip

- 动效细节（先布局后动画）
- 完美像素（还原度 80% 即可）
