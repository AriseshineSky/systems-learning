# Task: HTML + CSS 基础 & Box Model (C1)

**Status:** not started  
**Track:** css-engineering

## Goal

建立 Box Model 直觉与语义化 HTML 基础。没搞懂 Box Model，后面的 Flex / Grid 只会变成不断试数值。

## Must read (MDN Learn CSS)

- [ ] HTML 语义化：header / nav / main / section / article / aside / footer vs div
- [ ] 盒模型：content / padding / border / margin
- [ ] `box-sizing`：content-box vs border-box 的差异
- [ ] `display`：block / inline / inline-block / none
- [ ] width / height / margin / padding / border
- [ ] font / color / background / overflow

## Must understand

- [ ] 一个元素的「实际宽度」由哪些部分组成
- [ ] margin 合并（collapse）发生在什么情况
- [ ] 为什么项目里通常统一 `box-sizing: border-box`
- [ ] inline 与 block 元素在宽高 / 内外边距上的差异

## Hands-on

- [ ] 写一个语义化文章页（header / nav / main / article / footer）
- [ ] 写一个 Card（icon + title + text + button）
- [ ] 故意：不加 `box-sizing: border-box` 时给 Card 加 padding，看它变胖；再统一 border-box 看差异
- [ ] 故意：给相邻块 margin 重叠、给 margin 设负值，观察行为

## Optional

- [ ] 能画出一个 div 的盒模型分解图（content / padding / border / margin）
