# Task: 完整 Dashboard / SaaS (C8)

**Status:** not started  
**Track:** css-engineering

## Goal

终点检验：从「这个页面怎么写 CSS」变成「我知道这个页面应该怎么布局，然后只是把它实现出来」。

## 需求

一个响应式 SaaS Dashboard 页面：

- Sidebar（导航，移动端折叠）
- Header（搜索 + 用户菜单）
- Stat cards（4 个）
- 数据表格
- 图表占位（SVG / 假数据即可）
- 响应式：Desktop 三栏 → Tablet 两栏 → Mobile 单栏

## 流程

1. 先手绘 / 文字描述布局（不写代码）
2. 用 Grid 搭骨架，Flex 排细节
3. 视觉：套用 C5 的 token + C6 学到的层次
4. 组件：用 C7 的组件思维拆按钮 / 卡片 / 表格行
5. 最后 20% 时间做动效点缀（Optional）

## Output

- [ ] 完整页面在 3 个宽度下成立
- [ ] `notes/c8-dashboard.md` — 回顾：8 阶段各学到什么、还剩什么不懂
- [ ] 对照[完成标准](../00-roadmap/css-engineering-track.md)自查整轨

## Skip

- 前端框架集成（React 等）— 本轨专注 CSS 本身
- 完美设计（达到「整齐、有层次、可响应」即达标）
