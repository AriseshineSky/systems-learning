# Task: Tailwind + shadcn/ui + Component (C7)

**Status:** not started  
**Track:** css-engineering

## Goal

把前面学的 CSS 映射到 Tailwind，从「背 class」变成「理解 class」。你已有 Tailwind 经验，这里反而要慢。

## Must understand（先确认）

- [ ] `flex items-center justify-between` 各自对应什么 CSS
- [ ] `grid-cols-3 gap-4` 对应什么
- [ ] `md:` 前缀对应什么断点
- [ ] `p-6` / `px-4` / `mx-auto` / `max-w-6xl` 对应什么

## Hands-on

- [ ] 用 Tailwind 重写 C2 的 Navbar / Card / Button group（对着之前的 CSS 笔记写）
- [ ] 选一个 shadcn/ui 组件（Button / Card / Input），拆解它每个 class，能解释为什么
- [ ] 用 shadcn/ui 搭一个组件 gallery 页（按钮、输入框、卡片、badge、modal）

## 组件思维

- [ ] Button 的 variants：primary / secondary / ghost / outline；状态：hover / active / disabled
- [ ] 组件 = 间距 + 状态 + 一致性；不是复制粘贴

## Output

- [ ] `notes/c7-tailwind.md` — 一张「CSS 概念 → Tailwind class」对照表
- [ ] 组件 gallery 页面可运行
