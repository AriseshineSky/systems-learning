# Task: Flexbox (C2)

**Status:** not started  
**Track:** css-engineering

## Goal

看到页面就能自然想到 `display: flex` + `justify-content` / `align-items` / `gap`。这是最值得花时间的布局部分。

## Must read

- [ ] [A Complete Guide to Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/)（容器 + 子项）
- [ ] [Flexbox Froggy](https://flexboxfroggy.com/) 全部通关

## Must understand（容器）

- [ ] `flex-direction`：row / column，以及主轴 / 交叉轴
- [ ] `justify-content`（主轴）vs `align-items`（交叉轴）
- [ ] `gap`
- [ ] `flex-wrap`

## Must understand（子项）

- [ ] `flex-grow` / `flex-shrink` / `flex-basis`
- [ ] `flex: 1` 到底做了什么（grow 1 shrink 1 basis 0%）
- [ ] `align-self` 覆盖对齐

## Hands-on（每项先画再写）

- [ ] Navbar（logo + 链接 + 按钮，两端对齐）
- [ ] Sidebar（纵向导航）
- [ ] Card 布局（一组卡片 + 居中内容）
- [ ] Button group（间隔均分）
- [ ] Form（label + input 对齐）
- [ ] Pricing table（三栏等高）
- [ ] Header + content + footer 页面骨架（sticky footer 用 flex 实现）

## Output

- [ ] `notes/c2-flexbox.md` — 每项练习一条要点 + 你踩过的坑
- [ ] 能一眼说出：某个排版用 `justify-content` 还是 `align-items`（先判断主轴）
